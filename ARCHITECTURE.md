# Reef Keeper Architecture

*Last updated: June 2026*

## Core Philosophy

Reef Brain is the single source of intelligence for the app.

## High-Level Architecture

AI Vision Water Tests Maintenance Equipment Livestock Timeline \| v Reef
Brain \| +--\> Home +--\> Days-Off Planner +--\> Ask AI +--\> Future
Apex Integration

## Components

### Reef Brain

-   Tank score
-   Trend analysis
-   Recommendations
-   Daily briefing

### Reef Timeline

-   Unified event history
-   Search
-   Filters

### AI Vision

-   Photo analysis
-   Timeline integration

### Equipment Manager

-   Inventory
-   Service history

### Maintenance Engine

-   Maintenance logs
-   Planner integration

### Livestock Catalog

-   Livestock records
-   Growth tracking

### Storage

-   Persistent database
-   Shared data access

## Development Rules

1.  Reef Brain owns intelligence.
2.  Timeline owns history.
3.  Avoid duplicate calculations.
4.  Integrate new features into Timeline and Reef Brain.

## Release Workflow

1.  Feature branch
2.  Preview deployment
3.  Testing
